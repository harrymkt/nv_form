# nv_shortcut
This is a class that defines a custom shortcut.

`nv_shortcut(int k, bool ctrl = false, bool shift = false, bool alt = false, uint tap = 1);`

## Arguments:
- `int k`: One of the key constants to set.
- `bool ctrl = false`: Should the Control key be used?
- `bool shift = false`: Should the Shift key be used?
- `bool alt = false`: Should the Alt key be used?
- `uint tap = 1`: The number of taps, for multitap keys.
