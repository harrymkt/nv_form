# help_callback
Help callback of the control. Defaults to `null`.

`nv_form_control_callback@ help_callback;`

## Remarks:
This callback is identical to `callback` property, and if any is set, will be executed when you press `F1` on this control focused. Please note that if you set this callback, the `help` property will no longer be used, meaning if you want to show it, you will need to do it manually.
